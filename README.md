Archived NASA HUNCH program prototype (unfinished)

What is it for?
- A Nanolab, a very small scale enclosed environment that is used for ground and space experimentation.

What does this code do?

There are two modules:
* A custom serial monitor that is flexble with handling input and output from a COM port
* (unfinished) integrated temperature sensor, humidity sensor and camera drivers for the Arduino

What it would do?
- The serial monitor would allow for automatic connection and authentication with the Arduino Board and be able to send commands to the Arduino which it could format received data from temperature or humidity data and open a window to see a livestream from the camera connected to the Arduino.

What was the Result?
- Not really finished or got implemented into the actual project, but it was a learning experience with low level programming with Windows and Arduino as well getting into C++
